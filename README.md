# Q가이즈의 질문나무

수업 중에 학생이 한 좋은 질문을 학생별 나무에 열매로 모아 주는 웹 페이지입니다.

- **질문 등록**(`ask.html`): 학생이 반·이름을 고르고 질문을 보냅니다.
- **교사 검토**(`admin.html`): 선생님이 다듬어 승인하거나 보류합니다. 기록, 학생 명단, 화면 조절도 여기서 합니다.
- **질문나무**(`tree.html`): 승인된 질문이 열매로 열립니다. 열매를 누르면 질문이 쪽지로 펼쳐집니다.

나무는 달마다 새로 자라고, 질문은 엑셀이나 구글 시트로 남아 연말에 한 해를 돌아볼 수 있습니다. 로그인은 없고 링크만으로 씁니다. 데이터는 Firebase(무료 요금제)에, 페이지는 GitHub Pages에 둡니다.

설치와 사용법은 [설치안내.md](설치안내.md)에 있습니다.

## 개발

빌드 도구 없이 HTML과 자바스크립트 모듈만 씁니다.

```
node --test tests/*.test.js     # 계산·규칙·파일 맞물림 시험
node tests/serve.mjs            # Firebase 대신 가짜 저장소로 화면 띄우기 (http://localhost:8765/tree.html?c=x)
node tests/ui-smoke.mjs         # 위 서버를 켠 채로, Chrome 으로 화면을 눌러 보는 점검
```
